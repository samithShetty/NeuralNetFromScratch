A simple Neural Network built from scratch in Python. Comes with full (human-written) explanations for beginners who are trying to learn how they work. I originally built this to teach myself and Machine Learning and Neural Network concepts, so explanations focus on some of the concepts that I found most difficult in the beginning.

Just click on `main.ipynb` to see the full construction and explanations!


This Neural Network aims to read and classify handwritten digits, and was trained/tested on the famous MNIST Digit Dataset, retrieved from [Kaggle](https://www.kaggle.com/competitions/digit-recognizer/data)

Overall, I was able to achieve 93% testing accuracy using just a single hidden layer and straightforward backpropagation
